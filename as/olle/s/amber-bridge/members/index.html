AMBeR BRIDGE workspace

The members' layer exists today as a clickable prototype with example data. The shared platform gives it what it lacks: sign-in, roles, storage and backup.

Open the workspace prototype ↗

You are signed in as Olle Owner. Your role here is Administrator.

In this project your role can:

  • Read the notes in the workspace
  • Comment and suggest
  • Save new versions
  • Create notes
  • Restore earlier versions
  • Remove other people’s comments
  • Publish a version openly, and withdraw it
  • Edit the texts on the open pages (saved as a new version)
  • Publish a version of the page texts, or an earlier one again
  • Approve accounts and set roles

What happens in this workspace

  • InitiativesInitiatives on a board, each with problem, hypothesis, next step and lessons learned.
  • DocumentsDocuments with status (draft, for review, approved) and version history. Associated partners see the approved ones.
  • DiscussionsDiscussions and "Ask the network".
  • CalendarMeetings with decisions and actions.
  • NetworkThe organisations in the network.
  • Local guides and learningLocal guides with checklists per phase, and courses.

Tools

  • Shared notesWrite together. Every save is a named version that can be restored.
  • Page textsEdit the texts on the open pages, per language. Every save is a named version that can be undone.
