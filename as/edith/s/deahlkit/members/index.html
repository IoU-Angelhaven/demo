The DEAHLKit Studio

The Studio is where the language teams and the production team work on DEAHLKit together, in the browser: the course slide by slide, in every language, with the tools for layout, versions and review. It is in daily use on its own address, with its own sign-in. On the shared platform its accounts move to the common sign-in.

Open the course in the Studio ↗

You are signed in as Edith Editor. Your role here is Editor.

In this project your role can:

  • Read the notes in the workspace
  • Comment and suggest
  • Save new versions
  • Create notes
  • Restore earlier versions
  • Remove other people’s comments
  • Publish a version openly, and withdraw it

In use today

  • LayoutA language team chooses its language, a module and the Layout tab. Every slide is measured in the player, and text boxes where the text does not fit are listed with a suggestion. The team moves or resizes a box, changes the text size or writes directly in the box, and sees the result in the preview.
  • Versions and undoEvery save becomes a new, named version. Nothing is overwritten, and any change can be undone from the list of versions.
  • Menu titles and structureTeams write the menu titles themselves. Larger changes, such as removing, copying or moving a slide, are requested from the production team, with the module checked out while it is done.
  • Review per languageEvery spoken line, on-screen text and subtitle is reviewed and approved by the national team, with comments.

Next step

  • The English masterAn editor proposes a change on the page, an admin approves it and publishes a new master version. The change is then marked for review in every language that has the text.
  • Published language versionsEach published language has a reference copy. An editing round is opened for a language, the team works in it, and it is closed again.
  • New language versionsA new language takes the course in: translation, speech, films and course text, with the same tools the first seven languages were made with.
