The implementation model / Phase 3 / Activity 3.4

Activity 3.4

Define Outcomes and Targets

Clear, measurable results guide the work, make it possible to follow progress and show whether the implementation has succeeded. This activity describes what success looks like for clinical results, operations, users and the organisation, and turns it into specific targets with dates.

Well-defined results give stakeholders a shared understanding, support accountability, allow early correction and provide evidence for decisions on wider rollout. Develop them together with stakeholders so that they reflect different views.

Checklist

  • Hold workshops to agree what success means for patients and families, clinical staff, administrative staff, IT and leaders.
  • Define results in four areas: clinical (for example patient safety), operational (for example time saved), user experience (for example how much the solution is used) and organisational (for example cost or staff satisfaction).
  • Measure the current level (the starting point) before implementation starts.
  • Turn the results into SMART goals with target values, dates and milestones.
  • Show all areas together, for example in a balanced scorecard, so that no single measure dominates.
  • Write a measurement plan: what is measured, how, by whom and how often.
  • Report regularly against the targets, and review them as you learn.

Do you want to download the checklists and learn how to customise them for your own organisation? Go to Create your local guide.

Methods and tools

  • Logic model: A visual map that links resources and activities to results in the short and long term.
  • Theory of change: Explains how and why the planned activities are expected to lead to the wanted change.
  • SMART goals: Goals that are Specific, Measurable, Achievable, Relevant and Time-bound.
  • Balanced scorecard: A dashboard that shows results from several perspectives, such as clinical, operational, financial and user experience.
  • Key performance indicators (KPIs): Specific measures linked to the goals.
