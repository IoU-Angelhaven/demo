The implementation model / Phase 5 / Activity 5.2

Activity 5.2

Improve and Adjust (Iteration & Refinement)

Use the results of the evaluation to keep improving the solution. Also consider what should change next time, or in similar initiatives.

Problems will appear after launch. A clear routine for handling them leads to regular improvements and keeps the solution useful over time.

Part ofPhase 5: Evaluation
More in phase 5

  2. 5.2 Improve and Adjust (Iteration & Refinement)
  3. 5.3 Learn from the Project (Lessons Learned)

Checklist

  • Review the evaluation results regularly with users and stakeholders.
  • Identify problems, gaps and ideas for improvement, and rank them by benefit and effort.
  • Revisit the process map to see where the workflow or the solution needs to change.
  • Test new ideas on a small scale before wider use (PDSA cycles).
  • Treat larger changes as small implementation projects, with a plan, an owner and a follow-up.
  • Document each change and share it with users and stakeholders.
  • Consider whether the changes also apply to similar initiatives.

Do you want to download the checklists and learn how to customise them for your own organisation? Go to Create your local guide.

Methods and tools

  • Process map: A visual map of a workflow that helps to find problems and chances to improve.
  • Plan-Do-Study-Act (PDSA) cycles: Short test cycles that allow quick learning and adjustment.
  • Small implementation projects: A short version of the steps in this guide, used for each larger change.
